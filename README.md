# rotom-radio

rotom-radio is a repository containing all the scripts I wrote during my time at Green Giant FM, De La Salle University's student radio organization

# How to Run

## Pre-compiled

For Windows installs, you may use the [pre-compiled PyInstaller releases](https://github.com/K97i/rotom-radio/releases). No need to install Python and its dependencies.

## Manual 

### Pre-requisites

1. **Python**. This was developed and tested on **Python 3.12.3**, however, this would likely work on other versions. Feel free to test on the latest version!

### Steps
1. Install requirements:
```sh
pip install -r requirements.txt
```

2. Run:
```sh
python ./rotom-radio.py
```
